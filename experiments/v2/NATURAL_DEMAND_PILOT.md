V2 自然需求端到端实验
====================

本实验使用人工设计的 20 条自然需求，按直接回答、简单 agentic、普通多步、复杂多步
4:4:4:8 分层。它是合成业务场景实验，不是生产用户抽样，也不是独立双盲人口统计。
原始话术不包含工具数量、评分公式、DSL、事务对象数量等构建规格。

`natural_demand_20261010_01/manifest.json` 保存原始话术与样本分层。各样本的
`business.json` 是固定的业务规则、数据和来源声明；`user.json` 是固定的模拟用户事实；
`acceptance.json` 是隐藏的独立验收配置。`frozen.json` 记录所有输入文件的哈希。

执行顺序：

1. 原生 GPT-6.1-Sol 根据自然请求，从固定业务资料目录选择文档。
2. 解释业务意图与需要向用户澄清的信息，原始话术保留不变。
3. 作者根据需求、检索资料和服务端用户夹具生成沙箱。禁止重新编造数据和用户事实，
   禁止将私有值发布到初始接口。运行现有五项门禁与实际 Docker HTTP 验证。
4. 独立评审核对业务含义，只映射答案字段含义，不提供答案值。独立 Python 业务计算器
   从外部资料计算答案和全部最终状态；执行正确、错误、变更数据、旧答案和拒绝分支。
   验收配置及计算结果不反馈给作者，验收失败不增加作者修复预算。
5. 通过 RL 训练接口认证。
6. 新的原生策略会话仅接收公开接口和实际 HTTP 观察，实际询问用户、调用工具并提交。
   不读取参考轨迹、数据夹具、隐藏验收配置或评分目标，不用参考脚本冒充策略执行。

主指标为保守的“已验证端到端良品率”：完成所有上述阶段的样本数 / 固定 20 个需求。
另外报告原流水线合格数、外部业务验收数、训练就绪数、策略尝试数与成功数。
策略失败归为验证不确定，不能直接宣布沙箱存在缺陷。策略能力不足和环境错误必须分开。
结构正确、可运行和有区分度不证明实际训练能提升模型能力。

固定预算：并发 1，作者最多一次候选修复，桥接每调用 240 秒，单样本最多 1800 秒，
真实策略最多 40 个决策回合、每回合最多 8 个工具意图。策略工具意图由宿主执行，
Codex 会话不能在宿主执行任意工具。每笔业务事务仍须获得模拟用户实际授权。
所有失败、超时和不确定结果都留在分母；不在轮内修平台、不重跑终止样本、不挑选成绩。

业务资料检索目前是固定目录上的原生模型选文档，没有调用知识图谱。模拟用户沿用
v2 分层状态机；策略使用公开阶段接口提问，不把自由语言阶段解释能力算作已验证。
业务计算器与沙箱 DSL 独立，但语义审核和策略仍使用同一模型，存在相关性限制。
对于事务不足、授权失效等复杂负例，现有门禁与独立业务验证均参与检查；没有覆盖的
状态空间不应声称已经证明。

运行：

```sh
.venv/bin/python scripts/experiments/measure_v2_natural.py \
  --assets experiments/v2/natural_demand_20261010_01 \
  --output output/env_factory_v2_natural/round-01 \
  --connection output/code_agent_runtime_service_v2_240_recovery/connection.json
```

完成后生成 `results.json` 与 `sealed_manifest.json`；失败根因分析另存于轮目录之外，
不改动封存证据。

## 首轮结果与测量校正

`output/env_factory_v2_natural/round-01` 已完成并封存全部 20 个样本，耗时约 59.8 分钟。
流水线合格 13/20（65%）；原始端到端计数为 3/20，但存在答案布局、单位与单值包装
等测量问题，不能把该计数直接解释为真实业务良品率。

保持候选契约及原始证据不变，追加独立答案投影和真实拒绝语义检查后，
`round-01-audit-final` 探索性通过 7/20（35%）：直接回答 2/4、简单任务 1/4、
普通多步 3/4、复杂多步 1/8。这是事后测量校正，不能当作新盲测或修复后的良品率。
所有失败仍计入固定分母。四份封存证据的文件哈希均已复核。

本轮结束后通用修复包括：禁止评分目标引用策略自选观察 ID；提供显式、严格限幅的
数值比较；调用次数预算改为契约显式声明；正式策略不再能自行撤销模拟用户授权。
247 项 v2 与桥接回归测试通过。上述修复尚未在新的 20 样本轮中测量。
剩余重点为真实拒绝分支、无业务依据的强制步骤、候选修复回归及多事务阶段约束。
详细报告位于 `output/env_factory_v2_natural/round-01-report.json`，不属于封存成绩。
